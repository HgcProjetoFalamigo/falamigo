Privacidade

Política de Privacidade

Última atualização: [PREENCHER — data]. Escrita em linguagem simples, conforme a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018).

1. Quem somos

Falamigo é uma plataforma de comunicação assistiva desenvolvida pela HGC Software Solutions. Esta política explica, de forma clara, quais dados tratamos e por quê.

2. Dados de crianças e adolescentes

O Falamigo é usado por crianças — e tratamos a proteção desses dados com prioridade máxima:

  • O uso do aplicativo por crianças deve ser configurado e acompanhado por um responsável legal.
  • Não exibimos publicidade comportamental nem vendemos dados de qualquer usuário.
  • Os dados de uso são processados, sempre que possível, no próprio dispositivo (localmente).
  • Imagens, vozes e históricos de comunicação pertencem à família e podem ser excluídos a qualquer momento.

3. Quais dados coletamos

  • Dados de cadastro (quando houver): nome e e-mail do responsável, usados para criar a conta e permitir a recuperação de acesso.
  • Dados do perfil da criança: nome, idade e preferências visuais — armazenados para personalizar a experiência.
  • Dados de uso do aplicativo: frases montadas e símbolos mais usados, para sugerir vocabulário relevante. Esses dados são processados localmente sempre que possível.
  • Contato pelo site: quando você envia uma mensagem pelo formulário, recebemos o nome, e-mail e o conteúdo da mensagem — usados apenas para responder você.

4. Para que usamos

  • Manter o funcionamento do aplicativo e do site.
  • Personalizar a experiência de comunicação de cada usuário.
  • Responder solicitações de contato e suporte.
  • Melhorar o produto com base em dados agregados e anonimizados, nunca identificáveis.

5. Compartilhamento

Não vendemos nem alugamos dados pessoais. O compartilhamento só ocorre quando estritamente necessário para operar o serviço (por exemplo, provedores de nuvem), sempre com contratos de proteção de dados, ou quando exigido por lei.

6. Seus direitos

Você pode, a qualquer momento, solicitar a confirmação, o acesso, a correção ou a exclusão dos seus dados e dos dados da criança sob sua responsabilidade, bem como revolver o consentimento. Basta escrever para hgcssolution@hotmail.com.

7. Segurança e retenção

Adotamos criptografia em trânsito, controle de acesso e boas práticas de desenvolvimento seguro. Os dados são mantidos apenas pelo tempo necessário às finalidades descritas nesta política.

8. Contato do encarregado de dados (DPO)

Para qualquer dúvida sobre privacidade: hgcssolution@hotmail.com · HGC Software Solutions, Joinville/SC — Brasil.
